# LTspice Simulation & Noise Analysis SOP

A standard operating procedure (SOP) for setting up LTspice simulations and analyzing noise in a photodiode model.

## Photodiode Model Parameters

The following parameters are used to characterize the photodiode for noise analysis.

| Parameter | Symbol | Description |
|:---|:---:|:---|
| Junction Capacitance | $C_j$ | Capacitance across the photodiode junction |
| Shunt Resistance | $R_{SH}$ | Parallel resistance representing leakage paths |
| Dark Current | $I_D$ | Current flowing through the photodiode in the absence of incident light |

## Simulation Workflow

1. Configure the photodiode model parameters.
2. Set up the LTspice simulation circuit.
3. Run the simulation.
4. Analyze the noise characteristics and results.
