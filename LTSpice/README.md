# LTspice Simulation & Noise Analysis SOP

## Photodiode Model Parameters for Noise Analysis

| Parameter | Symbol | Description |
|:---|:---:|:---|
| Junction Capacitance | $C_j$ | Capacitance across the photodiode junction |
| Shunt Resistance | $R_{SH}$ | Parallel resistance representing leakage paths |
| Dark Current | $I_D$ | Current flowing through the photodiode in the absence of incident light |

## Circuit Model Parameters for Practice LT Spice Sim

| Parameter | Symbol | Description |
|:---|:---:|:---|
| Photocurrent | $I_L$ | Current generated by incident light |
| Dark Current | $I_D$ | Dark current of the photodiode |
| Shunt Resistance Current | $I_{SH}$ | Current through the shunt resistance |
| Output Current | $I_O$ | Output current |
| Diode Voltage | $V_D$ | Voltage across the diode |
| Output Voltage | $V_O$ | Output voltage |
| Junction Capacitance | $C_J$ | Capacitance of the photodiode junction |
| Shunt Resistance | $R_{SH}$ | Shunt resistance of the photodiode |
| Series Resistance | $R_S$ | Series resistance of the photodiode |

## Responsivity vs. Wavelength 
- responsivitiy of the photodiode is dependent on the wavelength of the incident light 
- max responsitivity is at 775nm (higher responsitivity with higher wavelength), plateaus after 775nm 
- find the optimum wavelength for chosen photodiode 
- diode current generated by incident light $I_L = r_phi*phi_e$ (r is diode flux responsivity & $phi_e$ is the radiant flux energy in W)
